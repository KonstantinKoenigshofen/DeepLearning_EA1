# DeepLearning_EA1
Github-Repository für die Einsendeaufgabe 1 im Modul Deep Learning. Die Aufgabe war es, ein vor-trainiertes Modell für Bilderkennung in einer Webanwendung zu verwenden. Dabei sollten zuerst falsch und richtig klassifizierte Bilder dargestellt werden. Weiterhin sollte der Nutzer eigene Bilder hochladen können, welche dann von einem Modell klassifiziert werden können. Link zur Webseite: <https://konstantinkoenigshofen.github.io/DeepLearning_EA1/>
